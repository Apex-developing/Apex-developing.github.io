# Apex Developing GitHub Pages

This repository contains a personal GitHub Pages site built with Jekyll and the Minimal Mistakes theme in dark mode.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000 in your browser.

## Deploy

Push changes to the `main` branch and configure GitHub Pages in the repository settings to serve the site.

## Structure

- `_config.yml` - site configuration
- `_data/navigation.yml` - navigation menu
- `index.md` - homepage
- `about.md` - about page
- `skills.md` - skills page
- `projects.md` - projects page
- `experience.md` - experience and education page
- `contact.md` - contact page
- `assets/css/main.scss` - custom styling
